# Library Tracker

A command-line program for tracking library books.

## Features
- Add Book: Allows users to add a book by entering its title and author.
- List Books: Displays all books with their availability status.
- Borrow Book: Allows users to borrow a book by entering its title. Shows an error if the book does not exist or is already borrowed.
- Return Book: Allows users to return borrowed books.
